# Fortnite Chest Counter

**Считает каждый сундук, который ты открываешь в Fortnite, матч за матчем, с оверлеем, который сливается с игрой.**

[**⬇ Скачать ChestCounter.exe**](../../releases/latest) · Windows 10 / 11 · бесплатно · без установки

</div>

---

> Это форк проекта [LED-N/Fortnite-ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter) с добавленным **русским языком**. Вся логика подсчёта — от оригинального автора; данные охоты за сокровищами (`content.json`) и картинки сокровищ по-прежнему загружаются из оригинального репозитория, а обновления программы — из этого форка.

Chest Counter читает повторы, которые Fortnite сохраняет после каждого матча, и ведёт счёт открытых тобой сундуков, а также **сокровищ охоты за сокровищами**, полученных из сундуков. Прозрачный оверлей показывает твои цифры поверх игры, а окно счётчика хранит всю историю, твои шансы на золотой облик и коллекцию сокровищ.

> Счётчик считает сундуки, **которые ты открыл**. Он не показывает, где сундуки на карте.

## Как это работает (и почему это безопасно)

Fortnite может записывать на твой ПК **файл повтора** каждого матча. Chest Counter читает эти файлы после окончания матча — и больше ничего.

- ✅ **Только чтение файлов повторов**: файлы `.replay` из `%LOCALAPPDATA%\FortniteGame\Saved\Demos`. Они открываются только для чтения и никогда не изменяются.
- ✅ **Никаких изменений игры**: папка установки Fortnite не трогается.
- ✅ **Никакого доступа к памяти игры** и никакого внедрения в процесс Fortnite.
- ✅ **В сеть выходит только к GitHub**: проверка новой версии (можно выключить) и однократная загрузка картинок сокровищ.

## Начало работы

1. В Fortnite включи повторы: *Настройки → Игра → Повторы → Запись повторов: Вкл.*
2. Запусти `ChestCounter.exe`. При первом запуске выбери язык — **Русский** (позже его можно сменить в *Настройках → Язык*).
3. Играй. Каждый матч засчитывается через несколько секунд после окончания.

Сундуки, открытые до начала использования счётчика, можно добавить карандашом у «Всего сундуков».

## Оверлей

Маленькое окно поверх игры (Fortnite в режиме «Оконный полноэкранный»).
- **Ctrl+Shift+O** — показать / скрыть
- **Ctrl+Shift+L** — закрепить / открепить (в закреплённом виде мышь проходит сквозь него)

Для стрима в OBS: *Источники → + → Браузер*, отметь *Локальный файл*, выбери `%APPDATA%\ChestCounter\overlay.html`, ширина 360 × высота 220 (450 × 300 для классического стиля).

## Параметры командной строки

```
--lang <fr|en|es|ru>   язык программы
--demos <папка>        папка повторов
--data <папка>         папка данных (по умолчанию %APPDATA%\ChestCounter)
--once                 проанализировать готовые повторы и выйти
--reset-config         снова задать вопросы первоначальной настройки
```

## Сборка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Запусти `build.bat` — готовый файл появится в `dist\ChestCounter.exe`.
